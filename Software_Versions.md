# Software versions

The following software environment was used for the EloKriti molecular-simulation and analysis workflow associated with the revised manuscript.

## Python and analysis software

- Python 3.11.14
- NumPy 1.26.4
- pandas 2.3.3
- SciPy 1.17.0
- scikit-learn 1.8.0
- matplotlib 3.10.8
- RDKit 2024.03.5

## Molecular-simulation software

- HTPolyNet 1.0.9
- GROMACS 2025.4
- AmberTools 24.8
- GAFF 1.81

A complete Conda environment specification is provided in `environment.yml`.
